# Uppurr 宠物营养助手 Demo

这是一个 React + Vite 网页 Demo，可部署到 Vercel、Netlify 或其他静态网站平台。

## 本地运行

```bash
npm install
npm run dev
```

## 打包

```bash
npm run build
```

## 部署到 Vercel

1. 打开 https://vercel.com
2. 登录后点击 Add New Project
3. 上传/导入本项目
4. Framework 选择 Vite
5. Build command: npm run build
6. Output directory: dist
7. 点击 Deploy

## 注意

这是产品 Demo，不是正式医疗/营养建议系统。正式版需要：
- 权威知识库
- 食材营养数据库
- 风险规则
- 兽医/营养师审核
- 隐私政策与用户协议
- 后端与 AI 接口
